# Official artwork (personal use only)

The owner asked for these to be used (#30, #33). The card back is the original image embedded in the Solo
Automa V1 PDF, extracted unchanged. The logos come from the official rulebook cover, which draws them at
high resolution: the cover was rendered at 6× and the logos cut out.

| File | What | Rights |
| --- | --- | --- |
| `automa-card-back.jpg` | Automa card back (518×759). The PDF draws "SOLO AUTOMA" as text on top of it, and the app does the same | Box art and logos © Space Cowboys / Asmodee and © MARVEL |
| `splendor-logo.png` | Splendor wordmark (640×233) with a transparent background. The navy behind it was removed with a colour-distance matte, estimated row by row, with un-premultiplied edges | Splendor logo © Space Cowboys |
| `marvel-logo.png` | MARVEL logo box (360×145), cropped exactly to the red box | MARVEL logo © MARVEL |

**Rules for this folder**

- Only `index.ts` imports these files. Use `OFFICIAL_ART` everywhere else.
- Don't add more official art.
- **Before the repository goes public**, delete this folder or replace it with original art. This is
  on the go-public checklist (#17).
